# AutoML Analytics Pipeline

An automated machine learning (AutoML) and analytics web application built with Python and [Streamlit](https://streamlit.io/). This tool allows users to upload datasets, run automated pipelines, explore data insights, and evaluate machine learning models seamlessly through an interactive user interface.

## 🚀 Features

* **Data Upload & Exploration:** Easily upload datasets (CSV, Excel) and view quick exploratory data analysis (EDA) summaries.
* **Automated Machine Learning:** Streamlined preprocessing and model training.
* **Interactive Dashboard:** Built with Streamlit for real-time visualization and metric tracking.
* **Comprehensive Documentation:** Includes detailed project reports and presentation PDFs.
